# Hello Streamlit App

A simple Streamlit application that says "hello" with interactive features.

## Features

- 👋 Personalized greeting
- 🎈 Interactive surprise button
- 🎨 Clean and modern UI
- 📱 Responsive design

## Installation

1. Install the required dependencies:
```bash
pip install -r requirements.txt
```

## Running the App

To run the Streamlit app, use the following command:
```bash
streamlit run app.py
```

The app will open in your default web browser at `http://localhost:8501`.

## Usage

1. Enter your name in the text input field
2. Get a personalized greeting
3. Click the surprise button for a fun animation
4. Enjoy the interactive experience!

## Requirements

- Python 3.7+
- Streamlit 1.28.0+
