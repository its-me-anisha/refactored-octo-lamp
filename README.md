# 🏳️ Country Flag Guessing Game

A fun and educational Streamlit app that tests your knowledge of world flags! Guess the country name from the displayed flag and learn interesting facts about each country.

## Features

- 🎯 **Interactive Gameplay**: Click the "Guess the Country Flag" button to start
- 🌍 **Complete Coverage**: Includes all 195+ countries of the world
- 🎨 **Beautiful Background**: Uses a custom countries flags background image
- 📊 **Score Tracking**: Keep track of your score and accuracy
- 💡 **Educational Facts**: Learn interesting facts about each country
- 🎮 **Multiple Choice**: Four options to choose from for each flag
- ✅ **Instant Feedback**: Immediate feedback on correct/incorrect answers

## How to Play

1. Click the "🎯 Guess the Country Flag" button to start a new game
2. A random country flag will be displayed
3. Choose the correct country name from the four options provided
4. Get instant feedback and learn a fun fact about the country
5. Click "🔄 Next Question" to continue playing

## Installation and Setup

### Prerequisites
- Python 3.7 or higher
- pip (Python package installer)

### Installation Steps

1. **Clone or download this repository**
   ```bash
   git clone <repository-url>
   cd cur_readbook
   ```

2. **Install required dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Streamlit app**
   ```bash
   streamlit run app.py
   ```

4. **Open your browser**
   - The app will automatically open in your default browser
   - If not, navigate to `http://localhost:8501`
